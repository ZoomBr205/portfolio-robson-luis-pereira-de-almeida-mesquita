# Sistema de Gestão Escolar

## 📌 Descrição
Sistema acadêmico com modelagem ER e desenvolvimento de scripts SQL para gerenciamento institucional.

## 🚀 Tecnologias
- MySQL
- SQL
- HTML
- CSS
- JavaScript

## ⚙ Funcionalidades
- Cadastro de alunos
- Cadastro de professores
- Controle de turmas
- Registro de notas
- Consulta acadêmica

## 🗄 Banco de Dados
Projeto focado em modelagem relacional, scripts SQL e organização de dados acadêmicos.
