# Predição de Churn

## 📌 Descrição
Projeto de Machine Learning desenvolvido para prever a saída de clientes utilizando algoritmos de classificação e análise de dados.

## 🚀 Tecnologias
- Python
- Pandas
- Scikit-Learn
- Matplotlib
- Jupyter Notebook

## ⚙ Funcionalidades
- Limpeza e tratamento de dados
- Treinamento de modelo preditivo
- Visualização de métricas
- Previsão de cancelamento de clientes

## 📊 Objetivo
Identificar padrões de comportamento que indicam possíveis cancelamentos de clientes através de técnicas de análise de dados e inteligência artificial.
