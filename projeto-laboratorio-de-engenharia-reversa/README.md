# Engenharia Reversa com IA

## 📌 Descrição
Projeto focado em reconstrução Full-Stack de aplicações utilizando IA generativa para apoio em engenharia reversa e documentação funcional.

## 🚀 Tecnologias
- React
- Node.js
- JavaScript
- MongoDB
- GitHub
- IA Generativa

## ⚙ Funcionalidades
- Reconstrução lógica de sistemas
- Estruturação de aplicações Full-Stack
- Geração automatizada de documentação
- Criação de interfaces modernas
- Organização de arquitetura de software

## 🧠 Objetivo
Aplicar conceitos de engenharia reversa e inteligência artificial na reconstrução e documentação de sistemas modernos.
